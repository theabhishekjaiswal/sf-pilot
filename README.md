# SF Pilot

SF Pilot is a premium navigation assistant designed to streamline your daily workflow in Salesforce. It provides a sleek, interactive interface that helps you switch views, access configurations, and navigate your org with ease.

---

## Key Features

### 🚀 One-Click Interface Switcher
* **Quick UI Toggle**: Transition between Salesforce Classic and Lightning Experience views instantly with a single click on the floating toolbar.
* **No-Override Standard View**: Open any standard record page directly, bypassing custom Visualforce or page overrides.

### 🔍 Unified Setup & Metadata Search
* **Global Search Panel**: Open a comprehensive search console from any page in Salesforce to find Objects, Settings, Custom Metadata, Apex Classes, and Visualforce pages.
* **Smart Filtering**: Type to filter setup categories and metadata dynamically, then click to open details in a new tab.
* **Quick Shortcuts**: Includes built-in deep links to frequently used admin pages like Application Test Execution, Deployment Settings, Deployment Status, Lightning Components, and Email Deliverability.

### 🗃️ Show All Data (Field Setup)
* **Metadata Insights**: View all fields and values for any record dynamically.
* **Direct Setup Links**: Click the wrench icon next to any custom field to instantly open its Setup configuration page.
* **Live Editing**: Make inline edits to record data. Unsaved changes are now safely dropped upon manual refresh to prevent stale data overrides.

### 🖱️ Draggable Navigation Bar
* **Movable UI**: Click and drag the SF Pilot logo to position the navigation bar anywhere on your screen.
* **Persistent Placement**: The extension remembers your custom coordinates across all Salesforce tabs.
* **Smart Upgrades**: The toolbar seamlessly handles live background data updates (like fetching Application Party IDs) without visual flicker or dropping your active drag session.

### ⚙️ Customizable Settings
* **Slide-in Settings Panel**: Access preferences via a sleek, animated dropdown.
* **Opacity Slider**: Adjust the translucency of the navigation bar with a live-updating slider.
* **Toggle Controls**: Enable or disable the entire navigation bar or just the dragging functionality at will.

### 🔄 Seamless Navigation Tracking
* **Smart Page Detection**: The assistant automatically detects and updates its status as you browse different records, ensuring a smooth, uninterrupted browsing experience.
* **Context Aware**: Intelligently disables itself on Setup pages (Flows, Object Manager, etc.) to prevent UI collisions.
