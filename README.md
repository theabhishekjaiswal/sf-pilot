# SF Pilot

SF Pilot is a premium navigation assistant designed to streamline your daily workflow in Salesforce. It provides a sleek, interactive interface that helps you switch views, access configurations, and navigate your org with ease.

---

## Key Features

### 🚀 One-Click Interface Switcher
* **Quick UI Toggle**: Transition between Salesforce Classic and Lightning Experience views instantly with a single click on the floating toolbar.
* **No-Override Standard View**: Open any standard record page directly, bypassing custom Visualforce or page overrides.

### 🔍 Unified Setup & Metadata Search
* **Global Search Panel**: Open a comprehensive search console from any page in Salesforce to find Objects, Settings, Custom Metadata, Apex Classes, and Visualforce pages.
* **Smart Filtering**: Type to filter setup categories and metadata dynamically, then click to open details in a new tab.

### ⌨️ Access Anywhere (Keyboard & Mouse)
* **Instant Hotkeys**: Press `Ctrl + Space` (Windows/Linux) or `Option + Space` (macOS) to toggle the search console from any record or Setup page.
* **Sleek Side Handle**: Click the unobtrusive handle on the right side of your screen to slide the search console open with your mouse.

### 🔄 Seamless Navigation Tracking
* **Smart Page Detection**: The assistant automatically detects and updates its status as you browse different records, ensuring a smooth, uninterrupted browsing experience.
